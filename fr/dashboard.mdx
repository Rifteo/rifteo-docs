## Vue d'ensemble du portail client

Votre tableau de bord vous accueille avec un résumé de l'activité récente et des métriques clés, ainsi que des accès rapides à vos audits, votre surface d'attaque et vos événements de sécurité dans le temps.

## Cartes principales

En haut du tableau de bord, les cartes clés résument votre posture de sécurité actuelle :

| Carte | Ce qu'elle affiche |
|---|---|
| **Actifs enregistrés** | Nombre total d'actifs dans votre inventaire |
| **Groupes d'audit** | Nombre de groupes d'audit |
| **Total des audits** | Nombre total d'audits réalisés |
| **Constats découverts** | Nombre total de constats découverts sur tous les audits |
| **Note de sécurité** | Note globale qui résume votre posture de sécurité |

Sous les cartes, vous pouvez passer entre trois vues :

- **Vue d'ensemble** : timeline des événements de sécurité, avec constats, remédiations et audits dans le temps
- **Audit Calendar** : audits planifiés et en cours
- **Surface d'attaque** : surface d'attaque surveillée

<Tip>
Dans l'onglet Overview, utilisez le sélecteur **All / Daily / Evolution** et le filtre de période pour ajuster l'affichage de la timeline.
</Tip>

## FAQ

<AccordionGroup>
  <Accordion title="Pourquoi mon tableau de bord n'affiche-t-il aucune donnée ?">
    Si vous n'avez pas encore lancé d'audit, vos cartes et graphiques affichent des valeurs à zéro jusqu'au démarrage de votre premier audit.
  </Accordion>
  <Accordion title="Que signifie ma note de sécurité ?">
    C'est une note globale qui résume votre posture de sécurité, basée sur les constats découverts dans vos audits.
  </Accordion>
  <Accordion title="Le tableau de bord est-il différent pour les Admins et les Membres ?">
    Les deux rôles voient la même vue d'ensemble du tableau de bord. Pour le détail complet des droits, consultez [Votre rôle](/fr/your-role).
  </Accordion>
</AccordionGroup>
